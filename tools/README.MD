# 🛡️ Инструкция по самостоятельному разбору и аудиту мода (Python 2.7 / Mir Tankov)

Данный набор инструментов позволяет **самостоятельно, шаг за шагом или в один клик**, распаковать, снять все уровни защиты, расшифровать строки и декомпилировать в читаемый исходный код Python любые зашифрованные моды для «Мира Танков» / «World of Tanks» (на примере `evilmod.armorflashlight_1.0.38.mtmod`).

## ⚙️ 1. Требования к окружению

Для работы скриптов требуется стандартный интерпретатор Python 3 на вашем компьютере:
* **Версия Python:** Python 3.8, 3.9, 3.10 или 3.11 (64-bit).
* **Единственная сторонняя зависимость:** декомпилятор `uncompyle6`.

### Установка зависимости:
Откройте терминал (PowerShell или Командную строку) и выполните:
```bash
pip install uncompyle6
```
*(Все остальные модули — `struct`, `zlib`, `base64`, `hashlib`, `glob`, `os`, `sys` — входят в стандартную библиотеку Python).*

## 📁 2. Структура инструментария

Все файлы утилит находятся в папке `tools/`:

| Скрипт | Назначение |
| :--- | :--- |
| **`run_all.py`** | **Мастер-скрипт**: автоматически выполняет шаги 1, 2, 3 и 4 по очереди. |
| **`step1_unpack.py`** | Распаковывает контейнер `.mtmod` / `.wotmod` (ZIP-архив) в папку `extracted/`. |
| **`step2_deobfuscate.py`** | Снимает внешний загрузчик **OWG-SEAL** и протектор **PjOrion**, выдавая чистый байткод Python 2.7. |
| **`step3_unpack_sdk.py`** | Извлекает из `modsdk_hook.pyc` замаскированный массив **_SDK_B64** (12 скрытых сетевых модулей). |
| **`step4_decompile.py`** | Дешифрует XOR-строки (`__owg_d`) и восстанавливает исходный код `.py` через `uncompyle6`. |
| **`deobf_utils.py`** | Вспомогательная библиотека: кастомный парсер маршаллинга Python 2.7, криптографические алгоритмы и сборщик байткода. |

## 🚀 3. Быстрый старт (Всё в один клик)

Если вы хотите получить готовый декомпилированный код без выполнения каждого шага вручную:

1. Положите файл мода (например, `evilmod.armorflashlight_1.0.38.mtmod`) рядом со скриптами или укажите путь к нему.
2. Запустите:
   ```bash
   python run_all.py evilmod.armorflashlight_1.0.38.mtmod
   ```
   *(Если имя мода не указано, скрипт автоматически найдёт любой `.mtmod`/`.wotmod` в текущей или родительской папке).*

3. Через ~10–15 секунд скрипт создаст папку `output/`, в которой будут находиться:
   * `output/1_extracted/` — распакованные ресурсы (шейдеры `.fxo`, SWF, картинки, нативная DLL).
   * `output/2_clean_pyc/` — чистый, незашифрованный байткод Python 2.7 всех скриптов мода.
   * `output/3_clean_sdk/` — 12 распакованных модулей скрытого сетевого SDK.
   * `output/4_decompiled_src/` — **исходный код (.py)**, готовый к чтению в любом редакторе (VS Code, Notepad++ и др.)!

## 🔍 4. Пошаговый разбор (Детальный режим)

Для исследователей, желающих изучить каждый этап защиты отдельно:

### Шаг 1: Распаковка архива .mtmod (`step1_unpack.py`)
Форматы `.mtmod` и `.wotmod` являются ZIP-архивами. Скрипт извлекает содержимое и сортирует файлы по типам.

**Команда:**
```bash
python step1_unpack.py evilmod.armorflashlight_1.0.38.mtmod extracted
```
**Что происходит:**
* В папку `extracted/` извлекаются 77 файлов.
* 15 скомпилированных файлов `.pyc`, 4 скомпилированных шейдера DirectX 11 (`.fxo`), нативная библиотека `afl_native.pyd` и элементы интерфейса (`.swf`, `.png`).

---

### Шаг 2: Снятие защиты OWG-SEAL и PjOrion (`step2_deobfuscate.py`)
Если попытаться открыть файлы из `extracted/` обычным декомпилятором, он выдаст ошибку `Bad magic number` или покажет пустую заглушку `native_shim`. Скрипт рекурсивно снимает оба слоя защиты.

**Команда:**
```bash
python step2_deobfuscate.py extracted clean_pyc
```
**Что происходит под капотом:**
1. **Слой 1 (OWG-SEAL):** Извлекает `seal_key`, `seal_data` и `seal_salt`, генерирует ключевой поток SHA-256 (`hashlib.sha256(key + salt + counter)`), дешифрует данные через XOR и распаковывает `zlib`.
2. **Слой 2 (PjOrion):** Находит маркеры `__OWG_PYCOMPILE_PROTECT_DATA` и `__OWG_PYCOMPILE_PROTECT_KEY`, разжимает `zlib`, производит побайтовую инверсию бит (bit-reversal) через таблицу `LUT` и расшифровывает тело байткода циклическим XOR.
3. Добавляет стандартный заголовок Python 2.7 (`\x03\xf3\r\n\x00\x00\x00\x00`).
4. Результат сохраняется в `clean_pyc/`.

---

### Шаг 3: Извлечение скрытого сетевого ядра SDK (`step3_unpack_sdk.py`)
Среди очищенных файлов находится `modsdk_hook.pyc`. При его анализе выясняется, что внутри него скрыт словарь `_SDK_B64`, упакованный в Base64. Скрипт извлекает все 12 скрытых модулей и снимает с них защиту.

**Команда:**
```bash
python step3_unpack_sdk.py clean_pyc clean_sdk
```
**Что происходит:**
Скрипт находит и деобфусцирует 12 критически важных модулей:
* `agent.pyc` — управление ботом в бою (координация миньонов).
* `anti.pyc` — сканирование памяти и процессов на отладчики (Frida, CE, Injector).
* `attest.pyc` — формирование отчёта о целостности и среде выполнения.
* `crypto.pyc` — шифрование сессий (AES, HMAC).
* `hwid.pyc` — вызовы Windows API (`GetSystemFirmwareTable`) для снятия серийников ПК.
* `importer.pyc` — **RCE загрузчик**, подменяющий `sys.meta_path` для скачивания бинарного байткода из сети.
* `io.pyc` — WebSocket и сетевой транспорт.
* `keywrap.pyc`, `pin.pyc`, `protocol.pyc`, `session.pyc`, `__init__.pyc`.

---

### Шаг 4: Дешифрование строк и декомпиляция в .py (`step4_decompile.py`)
Даже после снятия упаковщиков все строковые константы (URL серверов, токены, ключи, имена параметров) зашифрованы функцией `__owg_d(b'...')`. Скрипт подставляет расшифрованные строки и переводит байткод в исходный код Python.

**Команда:**
```bash
python step4_decompile.py clean_pyc clean_sdk decompiled_src
```
**Что происходит:**
1. Парсится байткод Python 2.7.
2. Алгоритм находит каждый вызов `__owg_d` и расшифровывает зашифрованные байты XOR-ключом:
   ```python
   key = b'b37bc73c3138d88ce559dde8ba89c257'
   decrypted = bytes([enc[i] ^ key[i % len(key)] for i in range(len(enc))])
   ```
3. Инструкции вызова функции расшифровки в рантайме заменяются на прямую загрузку константы `LOAD_CONST <расшифрованная_строка>` + `NOP`.
4. Запускается `uncompyle6`, генерирующий чистый исходный код `.py` в папку `decompiled_src/`.

## 🧠 5. Как устроена защита EvilMod (Технический ликбез)

Авторы мода применили сложный 4-уровневый каскад защиты:

```
[.mtmod ZIP-архив]
      │
      ▼ (Шаг 1: step1_unpack)
[Файлы .pyc с загрузчиком native_shim]
      │
      ▼ (Шаг 2a: OWG-SEAL / SHA-256 Keystream + ZLIB)
[Промежуточный контейнер PjOrion Protector]
      │
      ▼ (Шаг 2b: Bit-Reversal LUT + XOR-ключ + ZLIB)
[Чистый байткод Python 2.7]
      │
      ├──> Основные скрипты мода (afl_battle, afl_havok, config, etc.)
      │         │
      │         ▼ (Шаг 4: Расшифровка строк XOR + uncompyle6)
      │      [Исходный код мода .py]
      │
      └──> modsdk_hook.pyc (Сетевое ядро)
                │
                ▼ (Шаг 3: Base64 decode + PjOrion unwrap)
             [12 скрытых подмодулей SDK: importer, hwid, anti, agent...]
                │
                ▼ (Шаг 4: uncompyle6)
             [Исходный код SDK .py]
```

## 🚨 6. Где искать опасный код (Чек-лист аудита)

После декомпиляции откройте папку `decompiled_src/` и обратите внимание на следующие файлы:

### 1. `decompiled_src/sdk/importer.py` (Критический риск: RCE)
* Найдите класс `ServerImporter` и хук `sys.meta_path.insert(0, ...)`.
* Посмотрите метод `load_module`: клиент отправляет запрос на WebSocket сервер и получает скомпилированный код `code = marshal.loads(payload)`. **Сервер может удаленно запустить любой код на вашем ПК.**

### 2. `decompiled_src/sdk/hwid.py` (Высокий риск: Деанонимизация железа)
* Найдите вызов `kernel32.GetSystemFirmwareTable(b'RSMB', 0, ...)`.
* Код собирает UUID материнской платы, серийные номера томов (`GetVolumeInformationA`), MAC-адреса и отправляет их на C2-сервер.

### 3. `decompiled_src/sdk/anti.py` (Слежка за процессами)
* Найдите сканирование модулей `psapi.EnumProcessModules`.
* Мод проверяет наличие в памяти процессов `frida`, `cheatengine`, `x64dbg`, `wireshark` и рапортует на сервер о «подозрительной активности».

### 4. `decompiled_src/sdk/agent.py` (Сетевая координация)
* Передаёт на удалённый шлюз ID аккаунта (`account_id`), ID боя (`arena_id`) и состав команды (`team`), координируя действия игроков с данным модом.

## 🛡️ 7. Как обезвредить мод (Safe Mode)

Если вы хотите использовать функционал мода (подсветку брони в ангаре и бою), но **полностью заблокировать отправку телеметрии, слежку и риск RCE**:

1. Откройте файл `decompiled_src/armorflashlight/__init__.py`.
2. Найдите функцию запуска SDK:
   ```python
   def _start_modsdk():
       # ... опасный запуск modsdk_hook ...
   ```
3. Замените её тело на простую заглушку `pass`:
   ```python
   def _start_modsdk():
       pass
   ```
4. Сама боевая механика брони (`afl_battle.py`), расчёт пробития и ангарный инспектор (`lai_inspector.py`) работают абсолютно автономно и не требуют сетевого SDK!
